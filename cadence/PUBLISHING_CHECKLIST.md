# Anonymous GitHub publishing checklist

The repository files themselves are prepared without the original student name, student ID, institution name, lab/course identifiers, or institutional logo.

Before making the repository public:

1. Create a new repository rather than uploading the original ZIP into an existing repository with old commits.
2. Do not push the original PDFs, original filenames, screenshots, or source archive anywhere public.
3. Use a non-identifying GitHub account if the account itself must also be anonymous. A repository cannot hide the identity of the GitHub account that owns it.
4. Check the repository's commit history. Old commits can expose files that were later deleted.
5. Check Git author information and avoid personal email addresses. GitHub's privacy-protecting `noreply` address can be used for commits associated with an account.
6. Before publishing later additions, re-check screenshots and software project paths for usernames or personal folders.
7. Review GitHub profile fields, repository description, social links, and README links for identifying information.
